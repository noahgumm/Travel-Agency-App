# How to run

    1. Run create_and_populate_db.sql in order to populate the database
    2. Navigate to application.properties in the backend and change the database       username and password to match yours
    3. Make sure your database server is running and naviage to the root folder within the backend and run the command 'mvn spring-boot:run' from your terminal
    4. Navigate to the root folder of the front end and run 'ng serve'
    5. The application should now be available at 'http://localhost:4200'
